# Sayeb Portfolio

A React + Vite portfolio for MD Abu Ubaida Jubaer Sayeb, built with Framer Motion animations and responsive portfolio sections.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Project Files

- `SayebPortfolio.jsx` contains the portfolio UI components and section data.
- `src/App.jsx` mounts the portfolio component.
- `src/main.jsx` starts the React application.
- `src/styles.css` provides global browser-level styling.
- `vite.config.js` configures Vite with React.
